# 🛡️ VibeSafe VS Code Extension 사용 가이드 (User Guide)

**VibeSafe**는 VS Code에서 코드를 작성하거나 열었을 때 보안 취약점,
법적 리스크(개인정보보호법 등), API 키 노출로 인한 과금 위험 요소를
확인할 수 있도록 도와주는 보안 도구입니다.

위험한 코드를 발견하면 문제 위치와 설명을 보여주고, 검토해서 적용할 수
있는 범용적인 수정 예시를 함께 제안합니다.

## 1. 시작하기 (설치 및 실행)

### Extension 설치

1. VS Code의 Extensions 화면에서 `...` 메뉴를 누릅니다.
2. **Install from VSIX...**를 선택합니다.
3. `VibeSafe-0.1.0.vsix`를 설치하고 VS Code를 다시 로드합니다.

### 로컬 백엔드 실행

1. `VibeSafe-backend-0.1.0.zip`을 압축 해제합니다.
2. 압축을 푼 `backend` 폴더에서 `install.cmd`를 한 번 실행합니다.
3. 설치가 끝나면 `start.cmd`를 실행합니다.
4. VibeSafe를 사용하는 동안 백엔드 창을 열어 둡니다.

브라우저에서 아래 주소를 열었을 때 `"status": "ok"`가 표시되면
준비가 끝난 상태입니다.

```text
http://127.0.0.1:38457/health
```

이제 코드가 작성된 Python 파일을 열고, VS Code 왼쪽 Activity Bar의
**방패 모양 VibeSafe 아이콘**을 누릅니다.

## 2. 사이드바 위험 분석 패널 안내

VS Code 왼쪽의 **VIBESAFE: 위험 분석** 패널에서 현재 파일의 보안 상태를
한눈에 확인할 수 있습니다.

- **위험도 점수 바**: 현재 검사 결과를 0~100점과 색상으로 표시합니다.
- **감지된 위험 목록**: 위험 요소의 위치, 심각도와 요약 설명을 보여줍니다.
- **법적 리스크 ⚖️**: 관련 가능성이 있는 법률 조항을 참고 정보로 안내합니다.
- **API 과금 경보 💸**: 하드코딩된 API 키의 노출·무단 사용 위험을 경고합니다.

## 3. 주요 기능 및 사용법

### 🔍 타겟 코드 검사

패널 상단의 **지금 코드 검사하기** 버튼을 누르면 현재 파일을 검사하고
점수와 위험 목록을 갱신합니다.

Command Palette(`Ctrl+Shift+P`)에서 **VibeSafe: 현재 파일 분석**을
실행해도 같은 검사를 시작할 수 있습니다.

### 🛠️ 코드 수정 제안

탐지된 코드에 마우스 포인터를 올리면 더 안전한 구현 예시를 확인할 수
있습니다. 제안은 여러 환경에서 참고할 수 있는 범용 대체 코드이며,
프로젝트 구조와 실행 환경에 맞는지 검토한 뒤 적용해 주세요.

원하는 수정을 적용한 후 **지금 코드 검사하기** 버튼을 다시 누르면
위험도 점수와 탐지 목록이 최신 상태로 갱신됩니다.

### 📍 위험 위치 즉시 이동

패널의 **감지된 위험** 목록에서 항목을 누르면 에디터의 해당 코드 위치로
이동합니다.

## 4. 지원 언어 및 환경

- VS Code 1.85 이상
- Python 3.11 이상
- 최초 백엔드 설치 시 인터넷 연결
- 로컬 포트 `38457`, 포트 번호 중복을 피하기 위한 임의의 값입니다.

현재 백엔드 연동 분석은 Python 파일을 중심으로 제공합니다.

## 5. 자주 묻는 질문 (FAQ)

**Q. 취약 코드를 수정했는데 점수가 바로 바뀌지 않아요.**  
A. 여러 수정 과정에서 이전 분석 결과가 현재 파일을 잘못 가리키지 않도록
보호하는 동작입니다. 수정을 마친 뒤 **지금 코드 검사하기** 버튼을 누르면
최신 점수와 위험 목록으로 갱신됩니다.

**Q. 분석 요청에 실패했다는 메시지가 나와요.**  
A. 먼저 `backend/start.cmd`가 실행 중인지 확인하고 브라우저에서
`http://127.0.0.1:38457/health`를 열어 보세요. 응답이 없다면 백엔드를
다시 시작해야 합니다.

**Q. 수정 제안을 적용하면 무조건 안전한가요?**  
A. 수정 제안은 일반적인 안전 구현 예시입니다. 프로젝트의 프레임워크,
데이터 형식과 호환되는지 확인한 뒤 적용해야 합니다.

**Q. 소스 코드가 외부 서버로 전송되나요?**  
A. 기본 배포 설정에서는 같은 PC의 `127.0.0.1:38457` 로컬 백엔드로만
전달됩니다. 백엔드는 분석 결과나 소스 코드를 저장하지 않습니다.
