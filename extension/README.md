# 🛡️ VibeSafe

**VibeSafe**는 VS Code에서 AI 생성 코드와 일반 소스 코드의 보안 취약점,
법적 리스크, API 키 노출로 인한 과금 위험을 확인할 수 있도록 도와주는
코드 보안 분석 도구입니다.

코드를 검사한 뒤 위험 위치와 설명, 위험도 점수, 수정 제안을 한 화면에서
확인할 수 있습니다.

---

## 🚀 설치 및 실행

VibeSafe는 **VS Code Extension**과 **로컬 분석 백엔드**를 함께 사용합니다.

1. VS Code의 Extensions 화면에서 `...` 메뉴를 누릅니다.
2. **Install from VSIX...**를 선택하고 배포된 `.vsix` 파일을 설치합니다.
3. 함께 제공된 백엔드 ZIP을 압축 해제합니다.
4. Windows에서는 `backend/install.cmd`를 한 번 실행합니다.
5. VibeSafe를 사용할 때 `backend/start.cmd`를 실행해 둡니다.

백엔드 상태는 브라우저에서 아래 주소를 열어 확인할 수 있습니다.

```text
http://127.0.0.1:38457/health
```

`"status": "ok"`가 표시되면 분석 준비가 끝난 상태입니다.

---

## 🔍 코드 검사하기

1. VS Code에서 분석할 Python 파일을 엽니다.
2. 왼쪽 Activity Bar의 **방패 모양 VibeSafe 아이콘**을 누릅니다.
3. **지금 코드 검사하기** 버튼을 누릅니다.

Command Palette(`Ctrl+Shift+P`)에서 **VibeSafe: 현재 파일 분석**을 실행해도
같은 검사를 시작할 수 있습니다.

---

## 📊 위험 분석 패널

**VIBESAFE: 위험 분석** 패널에서 다음 정보를 확인할 수 있습니다.

- **위험도 점수 바**: 현재 검사 결과를 0~100점으로 표시합니다.
- **감지된 위험 목록**: 위험 위치, 심각도와 요약 설명을 보여줍니다.
- **법적 리스크 ⚖️**: 관련 가능성이 있는 법률 조항을 참고 정보로 안내합니다.
- **API 과금 경보 💸**: 하드코딩된 API 키의 노출·무단 사용 위험을 경고합니다.

위험 목록의 항목을 누르면 에디터의 해당 코드 위치로 이동합니다.

---

## 🛠️ 코드 수정 제안

탐지된 코드에 마우스 포인터를 올리면 더 안전한 구현 예시를 확인할 수
있습니다. 제안은 범용적인 대체 코드이므로 프로젝트 구조와 실행 환경에
맞는지 검토한 뒤 적용해 주세요.

코드를 수정한 뒤 **지금 코드 검사하기**를 다시 누르면 위험도 점수와
탐지 목록이 최신 상태로 갱신됩니다.

---

## 🔒 로컬 분석과 개인정보

기본 백엔드는 `127.0.0.1:38457`에만 열리며 외부 네트워크에 공개되지
않습니다. 분석할 코드와 파일 정보는 같은 PC에서 실행되는 로컬 백엔드로
전달됩니다.

백엔드 실행 창을 닫거나 `Ctrl+C`를 누르면 로컬 백엔드가 종료됩니다.

---

## ⚠️ 안내

- 현재 백엔드 연동 분석은 Python 파일을 중심으로 제공합니다.
- 탐지 결과와 위험도 점수는 보안 검토를 돕는 참고 정보입니다.
- 법률 정보는 법률 자문이나 규제 준수 인증을 대체하지 않습니다.
- 수정 제안은 자동으로 원본 코드의 안전성을 보장하지 않습니다.
