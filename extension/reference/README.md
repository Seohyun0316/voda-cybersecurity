# 보존 자료

이 폴더의 파일은 VibeSafe 확장의 실행·빌드 대상이 아닙니다.
기존 파일을 삭제하지 않고 출처와 용도를 분명하게 보존하기 위해 분리했습니다.

- `teammate-frontend/`: 기존 `extension/vibesafe/vibesafe/`에 있던 팀원 프론트엔드 원본 스냅샷
- `legacy-package-lock.json`: 기존 `PACKAG~2.JSO` 파일. 현재 `package-lock.json`과 내용이 동일한 보존본

실제 확장 코드는 `extension/src/`, 정적 자산은 `extension/media/`를 사용합니다.
