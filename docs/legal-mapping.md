## 1안: CWE별 경고 문구

| **유형(CWE)** | **경고문구** |
| --- | --- |
| SQL Injection (CWE-89) | 🚨 **SQL Injection이 탐지되었습니다.** 개인정보 유출 및 DB 변조 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| XSS (CWE-79) | 🚨 **XSS가 탐지되었습니다.** 세션 탈취 및 개인정보 유출 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| CSRF (CWE-352) | 🚨 **CSRF가 탐지되었습니다.** 비정상 요청이 수행될 수 있습니다. **전자금융거래법 제21조 관련 보안조치가 필요합니다.** |
| Dangerous File Upload (CWE-434) | 🚨 **위험한 파일 업로드가 탐지되었습니다.** 서버 침해 위험이 있습니다. **정보통신망법 제48조 관련 보안조치가 필요합니다.** |
| Missing Authorization (CWE-862) | 🚨 **접근 권한 검증이 미흡합니다.** 비인가 접근 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| Hard-coded Credentials (CWE-798) | 🚨 **하드코딩된 인증 정보가 탐지되었습니다.** 계정 정보 유출 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| Insufficient Randomness (CWE-330) | 🚨 **안전하지 않은 난수 생성이 탐지되었습니다.** 인증 우회 위험이 있습니다. **전자금융거래법 제21조 관련 보안조치가 필요합니다.** |
| Weak Cryptography (CWE-327) | 🚨 **취약한 암호화가 사용되었습니다.** 민감정보 유출 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| Plaintext Password Storage (CWE-256) | 🚨 **비밀번호가 평문으로 저장되고 있습니다.** 계정 정보 유출 위험이 있습니다. **개인정보보호법 제24조의2 관련 보안조치가 필요합니다.** |
| Path Traversal (CWE-22) | 🚨 **Path Traversal이 탐지되었습니다.** 중요 파일이 노출될 수 있습니다. **정보통신망법 제49조 관련 보안조치가 필요합니다.** |
| OS Command Injection (CWE-77,78) | 🚨 **OS Command Injection이 탐지되었습니다.** 시스템 명령 실행 위험이 있습니다. **정보통신망법 제48조 관련 보안조치가 필요합니다.** |
| Code Injection (CWE-94) | 🚨 **Code Injection이 탐지되었습니다.** 악성 코드 실행 위험이 있습니다. **정보통신망법 제48조 관련 보안조치가 필요합니다.** |
| Unsafe Deserialization (CWE-502) | 🚨 **안전하지 않은 역직렬화가 탐지되었습니다.** 원격 코드 실행 위험이 있습니다. **정보통신망법 제48조 관련 보안조치가 필요합니다.** |
| SSRF (CWE-918) | 🚨 **SSRF가 탐지되었습니다.** 내부 시스템 접근 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| Uncontrolled Resource Allocation (CWE-770) | 🚨 **자원 사용 제한이 없습니다.** 서비스 장애가 발생할 수 있습니다. **정보통신망법 제48조 관련 보안조치가 필요합니다.** |
| Excessive Authentication Attempts (CWE-307) | 🚨 **로그인 시도 제한이 없습니다.** 무차별 대입 공격 위험이 있습니다. **개인정보보호법 제29조 관련 보안조치가 필요합니다.** |
| Exposure of Sensitive Information (CWE-200, CWE-359) | 🚨 **민감한 개인정보가 노출**되었습니다. 개인정보 유출 및 프라이버시 침해 위험이 있습니다. **개인정보보호법 제29조** 관련 보호조치가 필요합니다. |
| Insertion of Sensitive Information Into Sent Data (CWE-201) | 🚨 **응답 데이터에 민감한 정보가 포함**되었습니다. 개인정보 유출 위험이 있습니다. **개인정보보호법 제24조의2 및 제29조** 관련 보호조치가 필요합니다. |
| Generation of Error Message Containing Sensitive Information (CWE-209) | 🚨 **오류 메시지에 민감한 정보가 포함**되었습니다. 시스템 내부 정보 및 개인정보가 노출될 위험이 있습니다. **개인정보보호법 제29조** 관련 보호조치가 필요합니다. |
| Insertion of Sensitive Information into Log File (CWE-532) | 🚨 **로그 파일에 민감한 정보가 저장**되었습니다. 개인정보 및 인증 정보 유출 위험이 있습니다. **개인정보보호법 제29조** 관련 보호조치가 필요합니다. |
| Improper Input Validation (CWE-20) | 🚨 입력값 검증이 미흡합니다. 악의적인 입력으로 인해 보안 취약점이 발생할 수 있습니다. 개인정보보호법 제29조 관련 보호조치가 필요합니다. |
| Improper Certificate Validation (CWE-295) | 🚨 인증서 검증이 올바르게 수행되지 않았습니다. 중간자 공격으로 개인정보 및 인증 정보가 탈취될 위험이 있습니다. 개인정보보호법 제29조 관련 보호조치가 필요합니다. |
