# 위험도 산정 공식

`위험도_측정식.pdf`의 산식을 서버와 VS Code Extension에 동일하게 적용한다.

```text
개별 raw = 빈도 점수 × 기술 심각도 × 법적 가중치
개별 점수 = raw / (3 × 4 × 5) × 100
종합 점수 = 현재 남아있는 findings의 개별 점수 중 최댓값
```

finding이 없으면 종합 점수는 `0`이다. 같은 위험이 여러 번 탐지되어도 합산하지
않으므로, 가장 높은 위험을 수정하면 다음으로 높은 finding 점수까지 내려간다.
점수는 `0`~`100` 범위에서 소수 둘째 자리까지 유지한다.

## 빈도 점수

LLM 생성 코드에서 오탐(`label_binary = 0`)을 제외한 진짜위험 254건을 분모로
계산한 CWE별 비중을 등급화한다.

| 진짜위험 비중 | 점수 |
| --- | ---: |
| 20% 이상 | 3 |
| 5% 이상 20% 미만 | 2 |
| 1% 이상 5% 미만 | 1 |
| 1% 미만 또는 미검출 | 0.5 |

PDF에 없는 CWE에는 희귀 빈도인 `0.5`를 기본값으로 적용한다.

## 기술 심각도

| severity | Extension severity | 점수 |
| --- | --- | ---: |
| High | `error` | 3 |
| Medium | `warning` | 2 |
| Low | `info` | 1 |
| Critical (`CWE-502`) | severity와 무관 | 4 |
